# 路线图

目标：让「一个会话 = 一组独立指纹实例」像浏览器标签一样自然，同时让 Agent 能稳定接管
而不抢用户的实例。每项都写清验收标准，方便后续迭代直接开 issue。

## 已完成（1.4.0）

- [x] 四页控制台 + 浏览器式实例标签
- [x] 会话 ↔ profile 独占锁，一个会话多实例
- [x] CDP 多路复用、实时视口、点击/键盘转发、检查器
- [x] 分组标签组视图、拖拽排序、9 字段排序、列表内文件夹标签
- [x] 启动器主界面镜像、自适应铺满、鼠标/滚轮/键盘/粘贴/IME 转发
- [x] 启动器窗口实例自动接管（`DevToolsActivePort`）
- [x] 启动器关闭自动拉起、路径自动解析与落盘
- [x] 32 个 MCP 工具、真实 E2E、共享状态
- [x] 自动生成工具文档 + Canvas 项目图鉴

## 下一步（1.5.x）

### 1. 跨会话独占冲突可视化

现在冲突只返回错误文本。目标是在面板里看到「谁占了哪个 profile」。

- 状态文件记录 `session_id` 与 `updated_at`，面板映射页展示占用方；
- 绑定冲突时提供「查看持有方 / 强制释放（需二次确认）」；
- 验收：两个会话抢同一 profile，第二个会话能看到持有方并一键释放。

### 2. Skill 录制器

- 面板录制导航、点击、输入、等待，生成 `steps` JSON 并在 Skill 页可编辑；
- 录制时过滤密码字段，除非用户显式勾选；
- 验收：录制一次登录流程，保存后在其他 profile 回放成功。

### 3. Cookie 编辑器与网络日志

- 实例页增加 Cookie 表格（域、路径、过期、HttpOnly），支持增删改；
- 通过 CDP `Network.*` 收集请求，提供过滤与导出 HAR；
- 验收：修改 Cookie 后刷新页面生效；HAR 可被浏览器 DevTools 打开。

## 中期（1.6.x）

### 4. 多启动器 / 远程节点

- 支持配置多个 ShardX 端点（本机 + 远程），profile 标注来源节点；
- 服务端按节点维护连接池与健康状态；
- 验收：两个节点各绑定一个实例，标签栏显示节点徽标，互不串线。

### 5. 健康仪表盘

- 展示每个实例的 CDP 延迟、截图帧率、事件队列积压、重连次数；
- 异常阈值告警到面板状态栏；
- 验收：拔掉一个实例的网络，仪表盘 5s 内标红并在恢复后自动转绿。

### 6. 测试与 CI

- 为 `router` / `workspace` / `cdp` 的纯逻辑补单元测试（Bun test）；
- GitHub Actions：typecheck + build + manifest validate；
- 验收：PR 必须通过三项检查才能合并。

## 长期

- 实例标签拖拽重排与分组；
- 代理延迟探测与自动切换建议；
- 批量启动/停止（按文件夹、按标签选择）；
- 面板内更新器：检查 GitHub Release 并提示升级；
- 英文界面与 i18n。

## 明确不做

- 不绕过 ShardX 的授权或计费；
- 不在面板里直接执行任意系统命令；
- 不把启动器 API 暴露到非回环地址（远程节点走独立鉴权设计）。
